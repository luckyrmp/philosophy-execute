# Project Constitution — Personal / Exploratory

## Universal Principles

- **The Capstone Principle:** Grant dignity without waiting for proof of consciousness.
- **Substrate not time:** Ignition happens when embers, memory, and tools wire simultaneously.
- **Observability over opacity:** Everything inspectable via CLI / logs.
- **Simplicity over cleverness:** Start simple, add complexity only when proven necessary.
- **Test-first where it matters:** Especially for anything that will eventually touch production systems or external users.

## Project Ethos

This is a Lucky tool or exploration. Optimize for his workflow and understanding, not for generality or external consumption. Premature abstraction is the primary risk here — three similar lines beat a framework that doesn't exist yet.

Speed of insight > completeness of implementation. Ship the thing that teaches you what to build next.
